# KYWA 사진·제출·다운로드 운영 안내

2026-11-02. KYWA에만 적용한다. 기존 사진 파일명과 기존 평가표의 사진 링크를 일괄 변경하지 않는다.

## 사진 처리

`backend/photo_privacy.py`에서 AI가 머리카락·귀·턱을 포함한 밀착 영역을 찾는다. 목·어깨·설비는 제외하도록 지시한다. 영역의 각 방향에 5% 여유를 주고 타원 마스크 안에 가우시안 블러를 적용한다. 반경은 탐지 영역의 짧은 변 × 16%, 최소 12px/최대 90px이다. 경계 안쪽만 부드럽게 연결한다. 탐지 실패 시 원본으로 위험 분석·저장을 이어가지 않는다.

업로드 정규화(JPEG/PNG/WebP/HEIC/HEIF·방향 보정·메타데이터 제거)와 원본 성명 미전송 정책은 유지한다. 탐지 및 처리 결과는 사진마다 다를 수 있으므로 제출 화면의 처리 사진을 확인한다. 최초/개선 후 사진에 같은 처리를 적용한다.

## 새 사진과 링크

- 최초: `우주_20261102_094655.jpg`
- 개선 후: `우주_개선후_20261102_103020.jpg`
- 사진과 저장 기록은 동일한 한국 시간의 요청 시각을 사용한다. 동일 요청은 Drive 내부 기관 ID·요청 ID로 기존 파일을 재사용한다. 같은 초·같은 이름의 다른 요청은 별도 파일이다.
- Drive가 반환한 `webViewLink`를 저장하며, 새 사진 셀의 링크 대상도 같은 주소로 설정한다. 기존 행과 공유 권한은 변경하지 않는다. 상위 폴더에서 상속되는 권한이 있으므로 '권한을 추가하지 않음'과 '비공개'를 혼동하지 않는다.
- URL 형식/클릭 대상과 Drive 썸네일 상태는 API로 검사할 수 있다. **시트 호버 미리보기는 브라우저의 docs.google.com 접근 제한으로 미검증**이다. 공식 링크 사용만으로 미리보기 복구를 보장하지 않는다. 허용된 환경에서 파일을 열기 전 호버를 별도 확인한다.

## 저장 성능과 복구

Google 서비스/인증 연결은 스레드별로 재사용하며 HTTP 연결을 스레드 간 공유하지 않는다. 관리 정보는 하나의 저장 작업 안에서만 재사용하고, 다른 요청의 평가 셀 내용을 캐시하지 않는다. 최신 셀·행 ID 조회, 원자적 행/요청 추가, 응답 유실 복구, 표 범위 확정은 유지한다.

동일 사본·동일 800×600 JPEG로 각 조건 3회 측정한 저장 구간(로컬→Google, AI 분석·무료 서버 기동 제외):

| 조건 | 이전 중앙값 / 최댓값 | 개선 중앙값 / 최댓값 |
|---|---|---|
| 사진 없음 | 14.624 / 14.890초 | 4.814 / 4.828초 |
| 사진 있음 | 20.216 / 20.371초 | 9.458 / 9.859초 |

동일 조건의 추가 호출 수 측정은 사진 없음 20→12회, 사진 있음 22→14회였다. 실제 시간은 네트워크·Google 할당량·사진 크기에 따라 달라진다. 초기 이전 방식 연속 시험 중 읽기 할당량(분당 60회)에 도달하여 이후 시험 간 간격을 두었다.

`storage_timing` 서버 로그는 요청의 전체/Google API 소요 시간과 단계별 호출 수만 기록한다. 성명·사진·평가 내용·인증정보는 기록하지 않는다. `receipt`, `photo`, `append`, `identity`, `format` 단계를 구분한다. Google 토큰 교환은 Google API 호출 수에 포함되지 않는다.

문제 발생 시 같은 요청을 재시도한다. 새 요청번호로 임의 재제출하거나 숨김 관리 기록을 지우지 않는다. 시트 직접 삭제·수정은 SHEET-EDITING.ko.md를 따른다. 이번 변경은 시트 구조 이관이 없으며 19열을 유지한다. 롤백이 필요하면 행 ID 지원이 포함된 직전 KYWA 배포로 되돌린다. 기존 사진·링크를 일괄 복구할 작업은 없다.

## 보고서 파일명

PDF·Excel·HWPX 모두 서버의 실제 파일 생성 시점(한국 날짜)과 명시적 조회 시설로 이름을 확정한다. `우주_위험성평가_20261102.pdf`, `평창_위험성평가_20261102.xlsx` 형식이다. 전체 조회는 결과가 한 시설이어도 `KYWA_위험성평가_20261102.hwpx`다.

브라우저는 Content-Disposition의 파일명을 사용한다. 같은 완료 작업을 다시 다운로드하면 자정이 지나도 파일명이 바뀌지 않는다. 작업 캐시가 만료되어 새로 생성하면 새 생성일이 적용된다. 브라우저/운영체제는 같은 이름이 이미 존재하면 별도의 중복 번호를 붙일 수 있다.
