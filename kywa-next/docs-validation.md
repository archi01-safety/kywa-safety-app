합성 평가 100건, 전후 사진 200장을 대상으로 로컬에서 생성했습니다.

| 형식 | 시간 | 파일 크기 |
|---|---:|---:|
| Excel | 3.46초 | 137,584 bytes |
| PDF | 3.31초 | 638,937 bytes |

측정 프로세스 최대 RSS: **298.2MiB**. 이 수치는 보고서 생성 전용 로컬 프로세스의 값입니다. 실제 Render CPU·메모리, Google 다운로드 지연, 여러 사용자가 접속한 상황의 보장값이 아닙니다. 결과 원본은 `artifacts/load-results.json`에 있습니다. 사진 처리와 보고서 생성은 하나의 메모리 작업 제한을 공유합니다.

## 실제 연결 후 확인할 항목

- Google OAuth 승인 계정, 개발 시트 쓰기·이력 기록, 비공개 Drive 업로드/읽기.
- 실제 Gemini 응답 및 선택 모델 사용 가능 여부. KOSHA는 아래 추가 검증에서 실제 검색·PDF 다운로드를 확인함.
- Render 무료 서비스의 7일 관찰 및 운영 전환. 현재 결과는 7일 관찰을 포함하지 않습니다.
- HWPX: 정상 샘플·원문 참고자료 제공 후 별도 구현.

Playwright 자동 E2E는 이 Windows 호스트에서 Chromium 기동 시간 초과로 실행을 완료하지 못했습니다. 이후 **Linux CI에서 PC·모바일 2개 모두 통과**했습니다. 검사 범위는 분석·수정·선택 제출, 개선조치·재평가·완료·재개, 이력, Excel/PDF 다운로드, 새로고침, 모바일 가로 넘침, 로그아웃·담당자 보고서 제한입니다.

의존성 경고: Starlette/Authlib에서 httpx 관련 예정된 변경 경고가 발생합니다. 현재 기능 검사에는 영향을 주지 않았으며, 잠금 파일 갱신 시 검토해야 합니다.

## 관리자 PIN·푸터 검증 (2026-09-29 추가, 미배포)

원본 개발 앱을 참고해 숫자 4자리 관리자 비밀번호와 안내 푸터를 추가했습니다. 실제 운영 비밀번호는 소스와 테스트에 넣지 않았으며 테스트는 별도 PIN을 사용합니다.

- 인증 검사: 앞자리 0, 잘못된 PIN, CSRF·Origin 위반, 익명 목록·사진·보고서·재평가 거절, 체험/Google 경로를 통한 우회 차단.
- 세션 검사: 로그인 시 CSRF 교체, 로그아웃한 쿠키의 재사용 거절, 서버 재시작 후 세션 거절, 접속 중에도 최초 로그인부터 1시간 후 만료.
- 시도 제한: 쿠키·IP 변경과 8개 동시 요청에도 계정 전체 5회 오류 제한, 15분 후 해제.
- 설정 검사: PIN 방식에서 Google OAuth 값 없이 실제 연동 설정 검사 통과, 잘못된 해시 기동 거절.
- PC 직접 확인: 잘못된 비밀번호 안내 → 정상 로그인 → 사본 129건 표시 → 로그아웃 후 0개 표시 및 잠금 화면 복귀.
- 모바일 직접 확인: 390px 화면에서 숫자 비밀번호 로그인·로그아웃, 두 관리 탭 잠금, 푸터 줄바꿈, 가로 넘침 없음.
- Next.js TypeScript 검사와 정적 빌드 통과. 기존 Python 검사와 새 PIN 검사 6개를 포함해 총 51개 항목 통과. 마지막 전체 실행에서는 기존 동시 제출 검사 1개에 Windows 임시 파일 공유 잠금(WinError 32)이 발생했으며, 해당 검사만 재실행하여 통과한 것을 확인했습니다. 나머지 50개는 전체 실행에서 통과했습니다.

화면 증거는 `artifacts/admin-pin-footer-desktop.png`, `artifacts/admin-pin-footer-mobile.png`입니다. PIN을 공유하는 방식이므로 개인별 본인 확인은 하지 않으며, 서버 재시작 시 실패 횟수가 초기화됩니다. 이번 검증은 로컬 사본 환경이며 운영 Google 데이터에 쓰지 않았습니다.

## 푸터 데이터 보안 문구 수정 (2026-09-29, 미배포)

사용자가 유료 Tier 2 사용 및 옵트아웃 적용을 확인하여, 제공업체 이름 없이 AI 분석 입력 정보의 모델 학습 미사용 안내를 추가했습니다. 외부 AI 서비스 전송과 개인정보 입력 주의사항도 유지했습니다. 이는 사용자가 확인한 설정을 반영한 것이며, 이번에 서비스 콘솔 설정을 별도로 검사하거나 변경한 것은 아닙니다.

Next.js TypeScript 검사와 정적 빌드를 통과했습니다. `http://localhost:8001`에서 제공하는 JavaScript 파일에 새 문구가 포함되어 있고, 페이지가 참조하는 정적 스크립트 7개가 로컬 빌드 파일과 일치함을 확인했습니다. 기존 화면 증거 이미지는 이번 문구 수정 이전 버전입니다. 이번에는 디자인과 Render 배포를 변경하지 않았습니다.

## 디자인·결과 표시·현황 개선 (2026-09-29 배포 준비)

네이비 메뉴, 중립색 본문, 주요 버튼 대비, 읽기 쉬운 글씨와 모바일 배치를 반영했습니다. PC 평가 결과 표와 모바일 카드에 분류·장소·위험상황·빈도·강도·점수·등급·관련근거·감소대책을 표시합니다. 모든 분석 항목에서 최대 3개의 KOSHA 키워드를 골라 첫 키워드를 자동 검색하며 다른 추천 키워드와 직접 검색도 지원합니다.

익명 현황 API는 연도별 시설·분류 건수와 완료 건수만 반환합니다. 평가 원문·사진·계정 정보는 반환하지 않으며 관리 목록과 보고서 인증은 유지합니다. Sheets 저장 시 위험도 숫자 열에 정수 표시 형식만 적용하고 빈 개선 후 셀은 채우지 않습니다. 이 변경은 운영 시트에 아직 실행하지 않았습니다.

Python 자동 검사 54개와 Next.js TypeScript/정적 빌드가 통과했습니다. 로컬 화면 접근은 브라우저 보안 정책에서 거절되어 해당 접근을 우회하지 않았습니다. 공개 배포 후의 시각·동작 검증 결과는 별도로 기록합니다. 운영 저장소 전환은 이번 디자인 배포에 포함하지 않습니다.
