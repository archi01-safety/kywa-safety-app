# 국가법령정보 OpenAPI 신청·서버 설정

2026-11-13 실제 신청 화면 확인 기준이다. 신청 주소는 https://open.law.go.kr/LSO/usrJoin.do 이며 본인인증·약관 동의·최종 신청은 계정 명의자가 수행한다. 개인 정보와 인증값을 이 문서에 기록하지 않는다.

## 시스템정보

- 도메인 있음: `kywa-safety.onrender.com`을 대표 주소로 등록한다. 입력란이 한 개이므로 7개 지원기관 운영은 활용 목적에 기재한다. 가입 후 관리 화면에서 추가 도메인 등록 방법과 필요 여부를 확인한다.
- 서버장비 IP는 필수 표시가 없는 항목이다. 우선 비우고 진행한다. 개인 PC 주소, DNS로 조회한 웹서비스 수신 주소를 서버의 API 호출 발신 주소로 오인해 입력하지 않는다. 발신 IP 등록이 요구되면 Render의 실제 발신 정보와 법제처 안내를 확인한다.
- API인증키(OC)는 현재 신청 화면에서 사용자가 직접 지정하고 중복확인을 하도록 안내한다. 과거 문서의 이메일 앞부분 예시를 현재 계정에 자동 적용하지 않는다.

## 활용 목적 예시

한국청소년활동진흥원(KYWA)의 AI 위험성평가 시스템 및 공공기관 기술지원 사업에 활용합니다. KYWA와 기술지원 대상 7개 기관의 웹 시스템에서 위험요인 분석 결과에 제시된 관련 법령의 명칭·조문·시행일을 조회하고, 국가법령정보센터 원문 링크를 제공합니다. 확인한 법령정보는 위험성평가 검토 화면과 Excel·PDF·HWPX 결과보고서의 관련근거 확인에 활용합니다. 법령정보를 임의로 변경하거나 법적 적합성 판정을 자동 확정하는 용도로 사용하지 않습니다.

## 공동활용 법령종류

접근분야는 인터넷이다. 현재 모바일 브라우저도 같은 서버 조회를 이용한다.

| 종류 | 목록 | 본문 | 용도 |
|---|---|---|---|
| 대한민국 현행법령 | XML·JSON | HTML·XML·JSON | 현재 구현한 법령명/조문 확인(XML 필수) |
| 현행 행정규칙·현행 자치법규 | XML·JSON | HTML·XML·JSON | 향후 고시·지침·조례 확인 범위 |
| 법령/행정규칙/자치법규 별표·서식 | XML·JSON | HTML | 향후 별표 원문 연결 범위 |

확장 항목을 신청했다고 해당 조회 기능이 구현된 것은 아니다. 판례·위원회 결정례·지능형 검색 API는 이번 기능의 필수 항목이 아니다. KOSHA GUIDE는 기존 공단 API를 별도로 사용한다.

## 서버 연결 및 검증

발급·승인된 OC를 Render 서버 환경변수 `LAW_API_OC`에 저장한다. 비공개 로컬 .env 또는 기존 서버 비밀설정 절차를 사용하고 공개 소스·대화·URL·다운로드 파일에 넣지 않는다. 도메인 추가가 필요하면 8개 기관에 동일한 키를 입력하기 전에 등록 범위를 확인한다.

현재 코드는 `lawSearch.do`의 시행일 기준 `target=eflaw`, `nw=3`과 `lawService.do`의 `MST`·`efYd`를 사용한다. 법령명·현재 시행일·조문 번호 및 제시된 조문 제목을 대조한다. API 오류 또는 대조 실패는 공식 검색 링크와 '원문 확인 필요'로 표시한다. 검색 링크가 열린다는 것만으로 조문 확인 성공으로 판정하지 않는다.

2026-11-13 사용자가 가입·신청을 완료하고 인증값을 비공개 설정으로 제공했다. 법령 목록·본문의 실제 인증 조회와 산업안전보건법 제38조, 산업안전보건기준에 관한 규칙 제3·4조 확인을 통과했다. 잘못된 제목과 존재하지 않는 조문은 확인 성공으로 표시하지 않는 것도 확인했다. 실조회 결과가 들어간 Excel·PDF·문단형 HWPX의 실제 링크 필드도 검사했다. 실제 Render에서 새 기능이 실행되는지는 별도 배포·운영 검증 결과를 따른다.

호출 헤더에는 해당 서비스의 APP_BASE_URL을 출처로 사용한다. 법제처 사이트인 것처럼 출처를 지정하지 않는다. 출처 헤더가 없는 요청은 실제 검사에서 필수입력 검증 응답을 받았으며, HTTP 200만으로 인증 성공으로 판단하지 않는다. 본문은 필요한 JO 조문만 요청하고 공개 링크에는 OC가 없는 공식 한글주소를 사용한다. 과거 버전 링크는 공식 규칙대로 (시행일자,공포번호,공포일자) 세 값으로 구성한다.

Render에는 사용자가 만든 `safety-law-api` 그룹의 LAW_API_OC를 사용한다. 8개 운영 서비스에만 Link only로 연결하고 시험 서버/다른 설정은 변경하지 않는다. 새 코드 배포 뒤 실제 서비스 경로와 출력물을 확인한다. 사용법은 [법령 원문 확인 안내](LAW-USER-GUIDE.ko.md)를 따른다.
