# 위험성평가 관련 법령 원문 확인

별도의 법령 API 로그인이나 사용자별 인증키 입력은 필요하지 않다. 서버가 공식 목록·본문에서 법령명·조문·시행일을 조회한다. 실제 사용 가능 시점은 HANDOFF.md의 운영 배포 완료 기록을 확인한다.

## AI 위험성평가

1. 현장 정보와 사진 또는 설명을 입력하고 기관명 AI 위험요인 분석 시작을 누른다.
2. 분석 결과 표의 **관련근거** 열에서 법령명 옆 ↗ 링크를 누른다.
3. 새 탭의 국가법령정보센터에서 해당 조문을 확인한다. **공식 원문 · 시행 YYYYMMDD**는 조회한 법령명·조문과 시행일을 확인한 경우에 표시한다.
4. **원문 확인 필요 · 법령 검색**은 제목 불일치·미확인 조항·조회 실패 등으로 조문을 확정하지 못한 경우다. 검색 결과에서 직접 원문을 확인한다. AI가 제시한 근거를 자동으로 적합성 판정한 표시가 아니다.

여러 법령·조문이 있으면 각각의 링크를 제공한다. 법령으로 해석하지 못한 참고문헌이나 KOSHA 지침을 임의의 법령 조문에 연결하지 않는다. KOSHA GUIDE는 기존 가이드 검색·다운로드 기능을 이용한다.

## 개선조치 · 재평가

담당자 로그인 후 위험요인 목록에서 평가를 선택한다. 상세의 **평가 기준 · 관련근거**를 펼치고 법령 링크를 누른다. 최초 평가 점수와 관련근거는 당시 기록을 유지하며 원문 연결 확인은 현재 시행 정보로 수행한다. 과거 데이터의 법령 문구를 일괄 바꾸지 않는다.

## 결과보고서

관리자 로그인 후 **결과보고서**에서 시설·기간·상태를 조회하고 Excel 다운로드/PDF 다운로드/한글 보고서를 누른다. 생성 과정에서 관련 법령을 확인하며 같은 조회·기록의 PDF/HWPX는 같은 검증 모델을 재사용한다.

- Excel: 위험성평가 시트의 관련근거 셀에 첫 링크가 있고, **관련근거** 시트에서 해당 건의 모든 법령 링크·확인 여부·시행일을 볼 수 있다.
- PDF: 붙임 세부 결과의 관련근거에서 법령명을 누른다.
- HWPX: 붙임의 관련근거에 한글의 실제 하이퍼링크가 들어간다. 한글의 링크 여는 단축키/클릭 방식에 따라 원문을 연다. 문장은 편집 가능하다.

출력 파일의 링크에는 인증값이 들어가지 않으며 원문 열람을 위해 API 계정으로 로그인할 필요가 없다. 네트워크 또는 법령 조회가 실패하면 공식 검색 링크와 확인 필요 표시를 사용한다. 링크 연결 성공과 개별 현장의 법적 적합성은 구분한다.
